# Screenshot convention

Screenshots in public documentation must be captured from the actual product and contain only synthetic or redacted data. Use a 16:10 capture at 1440×900, preserve the mode/evidence badge, and omit tokens, phone numbers, recordings, and raw webhook payloads.

Suggested files: `dispatch.png`, `booking.png`, `call-trace.png`, and `evals.png`. Replace the placeholder SVG only after visual QA.
